# SauceDemo Automation Testing Project

## Project Overview
This project contains manual testing documents and automation test scripts for the SauceDemo application.

The assignment includes:
- Bug reporting
- Test case design
- Selenium automation testing

## Application Under Test
Website:
https://www.saucedemo.com/

## Test Scenarios Automated
1. Valid Login
2. Add Product to Cart
3. Successful Checkout

## Tools & Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Maven
- ChromeDriver

    LoginTest.java
    CartTest.java
    CheckoutTest.java

     ProductPage.java
     CheckoutPage.java

## Test Execution Steps

1. Clone the repository
2. Open project in Eclipse/IntelliJ
3. Install Maven dependencies
4. Run TestNG test classes
